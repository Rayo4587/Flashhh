# SETUP INSTRUCTIONS

## Complete Setup Guide
1. **Clone the Repository:**  
   Open your terminal and run:
   ```bash
   git clone https://github.com/Rayo4587/Flashhh.git
   cd Flashhh
   ```

2. **Install Dependencies:**  
   Make sure you have the necessary dependencies to run the project. Run the following commands:
   ```bash
   npm install
   ```

3. **Build the Project:**  
   After installing the dependencies, build the project by running:
   ```bash
   npm run build
   ```

4. **Run the Application:**  
   Use the following command to start the application:
   ```bash
   npm start
   ```

## System Requirements
- OS: macOS, Linux, or Windows
- Node.js: v14 or higher
- npm: v6 or higher

## Troubleshooting
- **Error: 'module not found':**  
   Ensure that you have installed all the dependencies by running `npm install`.
- **Port already in use:**  
   If the server fails to start due to port issues, try changing the port in the configuration file or stop the process occupying the port.
